# 记录类型与数据导入

数据导入（`ir_data_import`）按记录类型做权限控制。本模块只提供两个开关，导入的完整设计见 `ir_data_import/doc/design.md`。

## 两个开关（由 ir_data_import 扩展）

| 位置 | 字段 | 作用 |
|---|---|---|
| 记录类型 | `allow_import`（允许导入） | 关闭后，该类型的记录不能通过导入新建、修改或删除，对所有人都一样（包括管理员） |
| 记录类型权限（类型 + 用户组） | `allow_import` | 关闭后，只有该用户组不能通过导入处理该类型的记录 |

两个开关都默认允许。它们显示在记录类型表单中，以及权限列表的最后一列。

## 每一行的检查顺序

1. 用户对模型有没有导入权限（导入权限表，`ir_data_import`）。
2. 行所涉及的类型的 `allow_import` 是否打开。新建检查新类型；修改检查原类型和新类型；删除检查当前类型。
3. 用户组对该类型的 `allow_import` 是否打开（管理员不受此项影响）。
4. 原有的 create / write / unlink 权限、记录规则和必填项。

任何一步不通过，该行报错，错误写在结果文件的 Validation Error 列。
